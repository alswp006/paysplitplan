## C. 배포 후 콘솔 설정 (수익·유통)

여기부터는 `ait deploy` **후**에 콘솔에서 하는 설정입니다 — 제출 **전**(A·B절)과 시점이 다릅니다.

1. **핵심 지표 → 활성 지표 정의**(재방문·체류시간·방문 횟수) — 미설정이면 토스가 활성 유저의 **유사 유저에게 앱을 추천**하지 않습니다(광고비를 안 쓰는 이 공장의 **유일한 무료 유통 스위치**가 꺼진 채입니다). **전환 지표 템플릿도 재선택 후 저장**하세요(일부 항목이 활성 지표로 이관됐습니다). 변경은 **다음 날부터** 적용됩니다.
2. **인앱 광고 분석** — 요청→수신→노출시도→노출성공 4단 퍼널과 유형별 **eCPM**을 확인합니다. **SDK 2.7.0 이상**이어야 하고, 업데이트 **이후** 데이터부터 수집됩니다(그 전 구간은 비어 있는 게 정상입니다).
3. **광고 그룹/슬롯 ID 발급 후 env 주입 재빌드** — 발급값은 빌드 시점에 앱에 박힙니다. 콘솔에서 발급만 받고 끝내면 앱은 그 값을 모릅니다 — **env 주입 후 재빌드·재배포**가 필요합니다.
4. **구독(IAP 정기 결제)을 쓴다면 webhook URL 등록**(필수) — **샌드박스가 없으므로** 실제 결제로 확인해야 합니다.
5. **사용자 정보 불러오기(토스 로그인)를 쓴다면** 콘솔에서 동의 화면을 설정하고 코드를 발급받으세요(한 번 요청에 **최대 5개** 항목). — 다만 **정말 필요한지 먼저 확인하세요**: `anonKey`는 서버 연동·동의 절차 **없이** 미니앱 안에서 바로 발급되고(미니앱마다 고유 · 같은 사용자는 항상 같은 값 · 검증 API 제공) 스마트발송·프로모션·토스페이에 그대로 쓸 수 있습니다. 토스 로그인이 필요한 경우는 **본인 확인·중복가입 방지처럼 앱인토스 밖 계정과 같은 사람인지 연결해야 할 때뿐**이고, 동의 화면 이탈률이 **절반에 가까운** 미니앱도 있었습니다(2026-07-23).
